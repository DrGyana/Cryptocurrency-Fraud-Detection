# Cryptocurrency-Fraud-Detection

This repository contains the implementation used in the paper:

"AI-Powered Case-Based Reasoning Approach for Cryptocurrency Fraud Detection: A Novel Hybrid Deep Learning Framework with Adaptive Similarity Metrics"

Authors: Gyana Ranjana Panigrahi, Jagjit Singh Dhatterwal, Rajesh Bingu, Ravneet Kaur, Chaitanya singla, Harpal Singh, Jay Prakash Singh.

Requirements Python 3.11

Install packages

pip install -r requirements.txt

Run python main.py
